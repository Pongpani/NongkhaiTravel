📌 NongkhaiTravel – A Tourism Information Website for Nong Khai, Thailand

NongkhaiTravel is a front-end web project designed to provide essential travel information for visitors exploring Nong Khai. The platform focuses on simplicity, modern design, and fast performance, making it easy for users to discover tourist attractions before their trip.

🚀 Tech Stack

HTML5 – Core structure of all pages

CSS & Tailwind CSS – Modern, utility-first styling for a clean and responsive UI

JavaScript (Vanilla JS) – Handles page interactions, data loading, and dynamic content

Vite – Development and build tool enabling fast bundling and optimized loading

🔍 Key Features

Highlights major attractions in Mueang Nong Khai District

Clean and minimalistic interface for straightforward navigation

Fast loading speed and optimized front-end architecture

Fully deployable as a static website (e.g., GitHub Pages, Netlify)
